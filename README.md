# Система обліку продажів v2

PWA-застосунок для обліку продажів у двох продуктових магазинах.
Стек: Google Apps Script (бекенд) + IndexedDB PWA (касир + адміністратор).

---

## 1. SETUP

1. **Створіть Google Spreadsheet**
   Відкрийте [Google Sheets](https://sheets.google.com) → Blank spreadsheet.
   Запам'ятайте ID таблиці з адресного рядка (між `/d/` та `/edit`).

2. **Відкрийте редактор Apps Script**
   `Розширення → Apps Script`.

3. **Скопіюйте всі файли бекенду**
   Для кожного файлу з папки `backend/` створіть відповідний файл у Apps Script:

   | Файл | Тип |
   |---|---|
   | `Utils.gs` | Script |
   | `Auth.gs` | Script |
   | `Shifts.gs` | Script |
   | `Inventory.gs` | Script |
   | `Sync.gs` | Script |
   | `Archive.gs` | Script |
   | `Backup.gs` | Script |
   | `Dashboard.gs` | Script |
   | `Code.gs` | Script |
   | `Setup.gs` | Script |
   | `appsscript.json` | Manifest (увімкнути через `Перегляд → Показати файл маніфесту`) |

4. **Запустіть `setupSpreadsheet()` вручну**
   `Виконати → Функція → setupSpreadsheet`.
   При першому запуску браузер запитає дозволи — підтвердіть.
   Після виконання таблиця матиме 13 аркушів.

5. **Заповніть аркуш «Налаштування»**
   Відредагуйте стовпець B для наступних параметрів:

   | Параметр | Що вписати |
   |---|---|
   | `ARCHIVE_FOLDER_ID` | ID папки Google Drive для архівів |
   | `BACKUP_FOLDER_ID` | ID папки Google Drive для резервних копій |
   | `API_SECRET` | Випадковий рядок 32+ символів (зберігайте в таємниці) |
   | `ADMIN_PIN` | SHA-256 хеш обраного PIN адміністратора |

   Для генерації хешу PIN: `Виконати → Функція → setAdminPin` з аргументом вашого PIN,
   або викликати безпосередньо: `setAdminPin('ваш_pin')` у консолі Apps Script.

6. **Розгорніть як Web App**
   `Розгорнути → Нове розгортання → Веб-застосунок`:
   - **Виконувати як:** Я (Me)
   - **Хто має доступ:** Всі (Anyone)

   Скопіюйте отриманий URL Web App.

7. **Вставте Web App URL у конфігурацію PWA**
   У `localStorage` кожного браузера встановіть:
   - Касир: `gasUrl`, `apiSecret`, `shopId` (`shop_1` або `shop_2`)
   - Адмін: `admin_gasUrl`, `admin_apiSecret`

   Або додайте сторінку першого запуску з формою налаштувань.

## 2. PWA DEPLOYMENT

1. **Розмістіть на статичному хостингу**
   Завантажте папки `cashier/`, `admin/` та `shared/` на:
   - [GitHub Pages](https://pages.github.com) (безкоштовно)
   - Netlify, Vercel або будь-який статичний хостинг
   - Власний веб-сервер із HTTPS (обов'язково — Service Worker не працює без HTTPS)

2. **На планшеті касира (Chrome)**
   - Відкрийте `https://ваш-домен/cashier/`
   - Chrome → `⋮ → Додати на головний екран`
   - Введіть назву «Каса» → підтвердіть
   - Відкрийте PWA — введіть у консолі або через сторінку налаштувань:
     ```js
     localStorage.setItem('gasUrl',    'https://script.google.com/macros/s/ID/exec');
     localStorage.setItem('apiSecret', 'ваш_api_secret');
     localStorage.setItem('shopId',    'shop_1');
     ```

3. **На телефоні адміністратора (Chrome)**
   - Відкрийте `https://ваш-домен/admin/`
   - Chrome → `⋮ → Додати на головний екран`
   - Введіть у консолі або через сторінку налаштувань:
     ```js
     localStorage.setItem('admin_gasUrl',    'https://script.google.com/macros/s/ID/exec');
     localStorage.setItem('admin_apiSecret', 'ваш_api_secret');
     ```

## 3. ПЕРШИЙ ЗАПУСК — SHOP_1

1. **Додайте співробітників до аркуша «Співробітники»**
   Заповніть вручну один рядок на кожного касира:

   | ПІН_Код | Імʼя_Продавця | Роль | Магазин_ID | Денна_Ставка | %_Тютюнові_вироби | … | Статус |
   |---|---|---|---|---|---|---|---|
   | `hashPin('1234')` | Іван Іваненко | Касир | shop_1 | 350 | 0.005 | … | Активний |

   Для отримання хешу: у Apps Script → `hashPin('ваш_pin')` → скопіюйте результат.
   PIN зберігається ТІЛЬКИ як хеш — вихідний PIN ніде не записується.

2. **Відкрийте PWA касира → увійдіть → відкрийте зміну**
   Введіть PIN → оберіть Магазин №1 → вкажіть показник лічильника → «Відкрити зміну».

3. **Відскануйте перший товар**
   Якщо товар відсутній у базі — з'явиться форма «Новий товар».
   Заповніть і збережіть — товар потрапить у кошик і в чергу синхронізації.

4. **Проведіть тестовий продаж**
   Натисніть «Провести» → перевірте що зміна у sync-dot на зелений.

5. **Закрийте зміну**
   «Закрити зміну» → введіть фізичну готівку → показник лічильника → підтвердіть.
   Система покаже нараховану зарплату.

6. **Перевірте адмін-панель**
   Відкрийте PWA адміністратора → дашборд → переконайтесь що продаж та зміна відображаються.

## 4. ДОДАВАННЯ SHOP_2

Зміни коду **не потрібні**. Вся логіка розділення по магазинах вже реалізована.

1. Додайте новий рядок у аркуш «Співробітники» з `Магазин_ID = shop_2`.
2. Встановіть PWA касира на другий планшет.
3. У `localStorage` другого планшета встановіть `shopId = 'shop_2'`.
4. Касир другого магазину входить зі своїм PIN — система автоматично
   розділяє дані, продажі, зміни та зарплату по `shop_id`.

Дашборд адміністратора відображає обидва магазини паралельно.

## 5. ОБСЛУГОВУВАННЯ

**Оновлення МРЦ на алкоголь**
- Відкрийте аркуш «Налаштування»
- Відредагуйте таблицю МРЦ (рядки нижче рядка `MRC_UPDATED`)
- Встановіть значення `MRC_UPDATED` на сьогоднішню дату
- Алерт «МРЦ не оновлювалось N днів» зникне з дашборду

**Щомісячне архівування**
- Автоматично: тригер спрацьовує 1-го числа о 02:00 (Europe/Kiev)
- Вручну: `Apps Script → Виконати → archiveMonth`
- Архів не запуститься якщо є відкриті зміни — спочатку закрийте всі зміни

**Встановлення тригерів** (виконати один раз після розгортання)
```
Apps Script → Виконати → setupAllTriggers
```
Встановлює:
- `dailyBackup` — щодня о 03:00
- `archiveMonth_` — 1-го числа кожного місяця о 02:00

**Перегляд резервних копій**
Google Drive → папка `BACKUP_FOLDER_ID` → файли `Backup_YYYY-MM-DD`.
Система зберігає 7 найновіших копій, старіші видаляються автоматично.

**Перегляд архівів**
Google Drive → папка `ARCHIVE_FOLDER_ID` → файли `Archive_YYYY_MM`.

## 6. ВИРІШЕННЯ ПРОБЛЕМ

**Синхронізація не працює (sync-dot залишається сірим)**
- Перевірте що `API_SECRET` в аркуші «Налаштування» точно збігається
  зі значенням у `localStorage` ('apiSecret') на планшеті касира
- Перевірте що Web App розгорнуто з доступом «Всі»
- Відкрийте консоль браузера (F12) — шукайте помилки мережі або CORS

**Штрихкод не знайдено (завжди з'являється форма «Новий товар»)**
- Товар відсутній у локальному кеші IndexedDB
- Підключіться до мережі → дочекайтесь синхронізації → оновіть кеш
- Або заповніть аркуш «Товари» вручну та виконайте примусову синхронізацію

**Неправильна локаль у формулах (десяткова крапка замість коми)**
- `Файл → Налаштування → Локаль` → встановіть «Україна»
- Роздільник у формулах має бути `;` (крапка з комою), не `,`
- Після зміни локалі перезапустіть `setupDashboard()`

**Планшет не зберігає на головний екран**
- Використовуйте тільки **Chrome** (Android) або **Safari** (iOS)
- Firefox та інші браузери не підтримують Web App Manifest на Android
- Сайт обов'язково має бути на HTTPS (не HTTP)
- На iOS: Safari → значок «Поділитися» → «На екран Домівки»

**Невірний PIN / не можна увійти**
- Переконайтесь що в аркуші «Співробітники» значення `ПІН_Код` —
  це SHA-256 хеш PIN, а не сам PIN
- Перевірте `Статус` співробітника — має бути «Активний»
- Перевірте `Магазин_ID` — має збігатися зі значенням `shopId` у `localStorage`

**Дашборд порожній після синхронізації**
- Переконайтесь що `setupDashboard()` було запущено після `setupSpreadsheet()`
- Перевірте що `Магазин_ID` у Продажі/Зміни = `SHOP_1`/`SHOP_2` (великими літерами)
  якщо формули дашборду посилаються на ці значення

## Структура проекту

```
backend/          Google Apps Script (.gs файли)
  appsscript.json
  Utils.gs        Утиліти, константи, HTTP-відповіді
  Auth.gs         HMAC-підпис, SHA-256, перевірка PIN
  Code.gs         doPost — точка входу, маршрутизація
  Setup.gs        Початкове налаштування таблиці
  Sync.gs         Пакетна синхронізація операцій
  Shifts.gs       Відкриття/закриття змін, зарплата
  Inventory.gs    Інвентаризація
  Archive.gs      Щомісячне архівування
  Backup.gs       Щоденне резервне копіювання
  Dashboard.gs    Налаштування дашборду в Sheets

shared/           Спільний код PWA касира та адміна
  constants.js    Константи (DB, статуси, локаль)
  crypto.js       SHA-256, HMAC-SHA256 (Web Crypto API)

cashier/          PWA касира
  index.html
  manifest.json
  sw.js           Service Worker (cache-first, офлайн)
  css/main.css
  js/
    app.js        Маршрутизатор екранів
    auth.js       PIN-авторизація (офлайн)
    db.js         IndexedDB (товари, зміни, черга)
    sync.js       Синхронізація з GAS
    scanner.js    HID + камера BarcodeDetector
    pos.js        POS-екран, кошик, продаж
    cart.js       Стан кошика
    shift.js      Відкриття/закриття зміни
    products.js   Форма швидкого додавання товару
    receipt.js    Прихід товарів
    expenses.js   Витрати
    utils.js      Формати, UUID, звуки, DOM

admin/            PWA адміністратора
  index.html
  manifest.json
  sw.js
  css/main.css
  js/
    app.js
    auth.js
    db.js
    sync.js
    utils.js      apiCall, форматування, HMAC
    dashboard.js  Дашборд + алерти + KPI
    reports.js    Звіти по змінах
    salary.js     Зарплата і виплати
    products.js   Управління товарами
    inventory.js  Інвентаризація
    expenses.js   Витрати
```
